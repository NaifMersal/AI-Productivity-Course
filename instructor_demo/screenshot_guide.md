## Screenshot Best Practices

### Framing
- Include the prompt AND at least the first part of the response
- Show the Claude interface elements (project name, chat history)
- Crop out personal bookmarks, tabs, sensitive info

### Annotations (add later in slides)
- Use red boxes to highlight key elements
- Add callout text explaining what to notice
- Number steps if showing a sequence

### File Naming Convention
```
session[#]_[descriptor]_[order].png

Examples:
session1_bad_prompt_01.png
session1_good_prompt_02.png
session4_chain_step2_03.png
```
