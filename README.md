# AI at Work: Build the Workflows That Win Back Your Week

This repository builds hands-on SDAIA workshops that teach professionals and faculty to
turn the work they repeat into reusable, measurable AI workflows. Workshops are **generated
from shared templates** so deck *structure* is authored once and only the *examples/data*
change per workshop. The root [`index.qmd`](index.qmd) is the portal.

| Workshop | Generated folder | Outline |
|---|---|---|
| Building Your Own AI Assistant (KSU, half-day) | `ksu-workshop/` *(gitignored, generated)* | [outline](examples/ksu/outline.md) |

## How it's built

Source of truth (committed): `templates/workshop/` (structural decks with the concepts
authored inline), `examples/<id>/` (per-workshop fragments + data + outline), and
`config/workshops.json` (the manifest). `build.py` renders these into each workshop's
`out_dir` (e.g. `ksu-workshop/`), which is **gitignored and regenerated** — never edit it
directly.

Placeholders in templates: `{{ key }}` → an inline string from `vars`; `<!-- EXAMPLE: key -->`
→ a fragment file from `examples/<id>/fragments/`. Adding a workshop = a new
`config/workshops.json` entry + an `examples/<id>/` folder + a portal row.

## Rendering Slides

This project uses [Quarto](https://quarto.org/). The project config (`_quarto.yml`) lives
at the **repo root** and applies SDAIA branding globally; run all commands from the repo
root. **Build first, then render** — the decks Quarto renders are generated by `build.py`.

```bash
python build.py            # regenerate the workshop folders from templates/ + examples/
quarto render              # render every deck into output/ (gitignored)
```

Render or preview a single deck with live reload:

```bash
quarto render ksu-workshop/slides/cowork_and_automation.qmd
quarto preview ksu-workshop/slides/cowork_and_automation.qmd
```

## Project Structure

- **`index.qmd`**: Root portal page linking the workshops (URLs mirror folder paths — keep them stable).
- **`build.py`** / **`config/workshops.json`**: The generator and its manifest.
- **`templates/workshop/`**: Shared structural decks (`index.qmd` run-of-show + `slides/*.qmd`), concepts authored inline.
- **`chunks/reference/`**: Canonical plain-language concept definitions (the shared source behind the slides).
- **`examples/<id>/`**: Per-workshop swappable layer — `fragments/`, `data/`, `outline.md`.
- **`_quarto.yml`** / **`slides_template/assets/`**: Root Quarto config and SDAIA brand assets applied globally.
- **`prompts/`**: Prompt guides and instructor templates.
- **`notes/`**: Loose planning notes, idea lists, and drafts.
