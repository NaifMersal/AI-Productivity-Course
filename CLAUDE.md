# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

**Claude Playbook Lab** - A 2-day (12-hour) instructor-led workshop teaching IT/IS/MIS managers to build effective AI prompts. The deliverable is a personal "Claude Playbook" prompt templates for business process automation.


### Key Files
- `outline.md` - Complete 2-day session breakdown (primary documentation)



## Core Teaching Framework

**R-C-T-C Pattern** (central to the curriculum):
- **R**ole: Who should the AI be?
- **C**ontext: What information should it have?
- **T**ask: What exactly should it do?
- **C**onstraint: What are the limitations/rules?

**Advanced Techniques**: Chain of Thought (CoT), Few-Shot Examples, Tree of Thought

## Agent Persona Requirements (from course.yaml)

When generating or modifying course content:
- Use management-friendly analogies, avoid technical jargon without explanation
- Follow "Explain → Demonstrate → Practice → Apply" cycle
- Maintain 70% hands-on building time, 30% theory
- Use "I like, I wish, I wonder" feedback framework
- Always connect activities back to the Playbook artifact
- Support dual-language (English + Arabic key terms)

**Day 2** - Engineering & Operations (Sessions 5-8)
