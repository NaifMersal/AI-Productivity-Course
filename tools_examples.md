# AI Tools Guide

## Text and Content Generative AI
*   **Gemini**: Google's multimodal AI capable of understanding and generating text, code, and more.
*   **NotebookLM**: An AI-powered research assistant that helps summarize and query documents.
*   **Anthropic Claude**: An AI assistant known for handling large context windows and nuanced tasks.
*   **ChatGPT**: A versatile conversational AI by OpenAI for drafting, brainstorming, and coding.
*   **Clockwise**: AI scheduling assistant that optimizes calendars for focus time.
*   **Grammarly**: AI writing assistant for checking grammar, tone, and clarity.
*   **Jasper**: AI content creation platform tailored for marketing and business needs.
*   **Microsoft Copilot**: AI assistant integrated into the Microsoft 365 ecosystem.
*   **Notion AI**: AI workspace assistant for writing, summarizing, and organizing notes.
*   **Zapier**: Automation platform using AI to connect and orchestrate workflows between apps.
*   **Google Sheets**: Spreadsheet tool using Gemini to analyze data, build trackers, and visualize insights.
*   **Google Meet**: Video conferencing app using Gemini for notes, captions, and custom backgrounds.

## Code-Generative AI
*   **Gemini Code Assist**: Enterprise-grade AI coding assistant from Google.
*   **GitHub Copilot**: AI pair programmer helping developers write code faster.
*   **Jupyter AI**: AI tools integrated into Jupyter notebooks for data science workflows.
*   **Tabnine**: AI code completion tool improving developer productivity.

## Image and Media Generative AI
*   **Gemini with Nano Banana**: (Multimedia generation capabilities).
*   **Asset Studio**: Tools for generating and managing digital assets.
*   **Adobe Firefly**: Creative generative AI engine for image and design creation.
*   **Canva Magic Design**: AI-powered design tool that generates templates and visuals.
*   **DALL-E**: OpenAI’s image generation model creating art from text descriptions.
*   **ElevenLabs**: AI voice technology for natural-sounding text-to-speech.
*   **Midjourney**: Generative AI service for creating high-quality artistic images.
*   **Runway**: AI tools focused on video generation and editing.
*   **Google Slides**: Presentation tool using Gemini to generate images and apply visual styles.
